# Screenshots

These are generated from **demo mode** (fictional data) so no real messages are exposed.

To regenerate:

1. Run the app in demo mode:
   ```bash
   python3 server.py --demo
   ```
2. Open <http://127.0.0.1:8768> (or the printed URL) in your browser, maximize the window.
3. Pick a conversation (e.g. "Alex Rivera"), click **✨ Analyze** to populate the insights panel.
4. Capture and save here:
   - `overview.png` — full window: thread list + conversation + AI insights
   - (optional) `privacy.png`, `import.png`, `qa.png` for other features

Keep every screenshot to demo data only — never commit real conversations.
